*DeltaruneOS* - A deltarune inspired WebOS!! 
<img width="1917" height="860" alt="finaldos" src="https://github.com/user-attachments/assets/6669b42c-901b-49ec-b199-851e8574b5ec" />

Built with html/css/js, it features draggable windows which you can also open/close, serving as apps. The apps are the introduction, a wiki app, a timer app, a browser and dog. On other stuff, it has a live time+date on the top bar, an analog clock widget, draggable gifs and some music! Also, for the timer app i used this tut: https://medium.com/@ayushmanbilasthakur/how-to-make-a-simple-timer-using-html-css-and-javascript-3b07bee8819d
