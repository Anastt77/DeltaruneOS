*DeltaruneOS* - A deltarune inspired WebOS!! 
<img width="1632" height="840" alt="intro" src="https://github.com/user-attachments/assets/c9153b1e-2d50-4726-b4fc-adb180af0fc3" />
Built with html/css/js, it features draggable windows which you can also open/close, serving as apps. The apps so far are the introduction, a wiki app, and a functional timer app. On other stuff, it has a live time+date on the top bar, as well as a draggable tenna gif! Also, for the timer app i used this tut: https://medium.com/@ayushmanbilasthakur/how-to-make-a-simple-timer-using-html-css-and-javascript-3b07bee8819d
